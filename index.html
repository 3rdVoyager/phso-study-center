Welcome to the Pilgrimage Homeschool Resource Vault

The Pilgrimage Homeschool Resource Vault is a student-run directory of Science Olympiad resources. It indexes publicly-available study materials, tournament collections, and archived web resources to make them easier to discover and browse.

Use the External Resource Index to search and filter collections by year, division, and level. Toggle between grid and list views to browse the results.

If you own or are affiliated with any listed resources and want them removed, please use the contact/report link in the footer and include the resource URL.

Disclaimer and Content Policy

This website is an independent, non-commercial study tool created by students, for students. It organizes publicly available Science Olympiad resources to help teams prepare. This site does not host or store files; it is a directory linking to external resources.

If you own or are affiliated with a resource and would like it removed, please contact us. We will verify requests, remove the link from the index, prevent re-adding, and follow up within a few days.
